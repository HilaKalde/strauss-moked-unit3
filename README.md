# שטראוס · מוקד המכירות · יחידה 03 – מערכות ליבה, מרכזייה וכלי תקשורת

לומדת HTML ליחידה 03 בתכנית ההכשרה של מוקדני המכירות בשטראוס, לפי התסריט.

- קובץ אחד עצמאי: `index.html` (גופנים, תמונות, צילומי מסך, סרטון וצלילים מוטמעים בקובץ).
- במה 1200×675, מותאמת לכל גודל מסך.
- 28 מסכים: פתיחה, מה נלמד, מסך ניווט, שולחן המערכות, סימולציות על צילומי מסך אמיתיים (Salesforce, SAP, הקשה מרוכזת, הפורטל, המרכזייה, Genesys), תהליכי עבודה, תרגיל התאמה, 2 שאלות תרגול, סיכום וסיום.
- מסך ניווט: בסוף כל פרק חוזרים אליו, ופרק שהושלם מסומן ב-✓.
- בכל מסך הערות הפקה (`data-note`) לקראת ההמרה ל-Storyline.

לצפייה: פותחים את `index.html` בדפדפן.
